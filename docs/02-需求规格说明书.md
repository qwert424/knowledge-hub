# 02 需求规格说明书

> 优先级：P0 首期必做 / P1 二期 / P2 可选
> 所有页面遵循统一设计系统（Ant Design 5 + 自定义 Token），中后台表格/表单风格一致；用户端采用对话式布局。

## 1. 角色与权限

| 角色 | 说明 | 默认权限 |
| --- | --- | --- |
| 平台超管 | 部署方 | 全租户、系统设置、集成配置 |
| 租户管理员 | 企业管理员 | 本租户全部知识库、成员、配置、审计 |
| 知识库管理员 | 指定 KB 负责人 | 该 KB 的文档、成员、索引、检索配置 |

| 访客 | 未绑定飞书/外部 | 仅 public 知识库只读 |

权限模型详见 [04](./04-数据源归一化与权限模型.md)。

### 2.2 交互要求（对标千问/文心）

- 欢迎页：居中输入框 + 推荐问题（来自知识库热门/管理员配置）+ 能力说明。
- 流式输出：首字 < 2.5s；支持“停止生成”；失败可重试且不重复计费。
- 引用：正文用 `[1][2]` 角标，右侧卡片联动；点击定位原文块。
- 多轮：默认带最近 N 轮 + 会话摘要；支持“新会话继承知识库选择”。
- 无答案：明确提示“知识库中未找到依据”，并展示可能相关的文档，不编造。
- 响应式：≥1280 三栏，768–1280 双栏，移动端单栏 + 抽屉。
- 可访问性：键盘发送、焦点管理、对比度 AA。

## 4. Agent 能力需求

### 4.1 主 Agent（对话）

- 识别意图：闲聊 / 知识问答 / 文档操作 / 数据分析 / 转人工。
- 工具：`retrieve`（混合检索）、`milvus_query`（按 ID 补查）、`graph_query`、`get_doc_url`、`web_search`（可选）、`sandbox`（可选）。
- 多轮记忆：会话摘要 + 最近轮次 + 结构化槽位。
- 引用：所有事实性回答必须带来源；无来源则明确说明。
- 拒答：越权、无依据、敏感内容。
- 流式：token、工具开始/结束、引用、错误事件。
- 中断：用户可停止；后端记录 partial。

### 4.2 检索 Agent（Agentic RAG）

- 首轮材料注入 → 判断证据缺口 → 改写查询 → 多轮补查（最多 N 轮）。
- 可按文档/目录/标签限定范围；可沿父块、相邻块、引用块扩展。
- 输出结构化：`status`（answered/partial/unanswerable）、`answer`、`sources`、`gaps`。
- 预算：最大轮次、最大 Token、最大耗时；超限降级为“部分回答”。

### 4.3 索引 Agent（后台触发）

- 解析 → CIR → Block 树 → 切片 → 增强 → Embedding → 写入 → 发布。
- 每一步可重试、可跳过、可观测。
- 支持多解析器路由与降级。
- 支持图片理解、表格结构化、OCR。

### 4.4 图谱 Agent

- 实体/关系抽取（JSON Schema 约束）。
- 实体消歧与合并。
- 社区发现与摘要。
- 增量更新：按文档删除旧边、重算受影响社区。

## 6. 验收标准（P0）

1. 管理员上传 PDF/DOCX/MD，5 分钟内完成索引，切片可在后台查看并重切。
2. 普通用户只能检索到被授权文档；撤销权限后 60 秒内生效（缓存 TTL）。
3. 对话回答首字 ≤ 3s，所有事实性回答带可点击引用。
4. 混合检索（稠密+BM25）在基准集上 Recall@5 ≥ 0.8。
5. 索引失败可在后台看到明确错误并一键重试；重试幂等。
6. 每次对话可在审计中查到用户、KB、命中文档、Token、成本、耗时。
7. 飞书 @机器人 可流式返回卡片答案，引用可展开。
8. 管理端 8 个模块均可完成增删改查与权限控制。
9. 租户 A 无法通过任何接口读取租户 B 数据（含 ID 遍历）。
10. `docker compose up` 一键起基础设施，四端各自可独立启动与健康检查。
